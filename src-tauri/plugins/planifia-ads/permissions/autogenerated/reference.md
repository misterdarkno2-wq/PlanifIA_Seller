## Default Permission

Permite a la ventana principal mostrar anuncios de AdMob y gestionar el consentimiento.

#### This default permission set includes the following:

- `allow-init-ads`
- `allow-get-ads-state`
- `allow-show-banner`
- `allow-hide-banner`
- `allow-load-interstitial`
- `allow-show-interstitial`
- `allow-load-rewarded`
- `allow-show-rewarded`
- `allow-show-privacy-options`
- `allow-register-listener`
- `allow-remove-listener`
